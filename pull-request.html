Pull Requestプルリクエスト

ひとことでいうと

自分の変更を取り込んでほしい、とレビュー付きで提案する仕組み（PR）。

1

なぜ生まれた？

mainに直接pushすると、レビューも議論も残らず、壊したときに取り返しがつきにくい。

2

それまでどうしていた？

完成したと思った時点で本流にマージし、問題は後から気付いていた。

直接マージPull Request
レビュー口頭や事後差分を見てから取り込める
議論チャットに流れるPR上に残る
CI手動PRをきっかけに自動実行しやすい
権限誰でも本流を触る提案と承認を分けられる
3

Pull Request で何ができるようになった？

変更を提案してレビューできる
議論と履歴が一つの場所に残る
CIやデプロイの起点にしやすい
ひとことメモ

GitLabではMerge Requestと呼ぶことも。中身の発想はほぼ同じ。
「PR出す」は提案の提出、の意味で使われる。
