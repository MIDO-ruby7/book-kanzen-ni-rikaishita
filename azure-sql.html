Azure SQLアジュールエスキューエル

ひとことでいうと

SQL Serverを土台にしたAzureのマネージドRDB。

1

なぜ生まれた？

DBサーバーのパッチ当てやバックアップを自前で続けるのは重い。
これらをクラウドに任せ、SQLだけ使いたい要望が生まれた。

2

それまでどうしていた？

自前のサーバーにSQL Serverを入れ、更新やバックアップを自分でしていた。

自前DB運用Azure SQL
運用作業自分でパッチ・バックアップAzureが実施
エンジンSQL Serverを自分で導入SQL Serverがベース
種類1種類を手で構築用途別に複数
3

Azure SQL で何ができるようになった？

SQL Serverを管理済みで利用
自動バックアップで復元
更新作業はAzureが担当
ひとことメモ

Azure SQLは、設備の保守までやってくれる貸し厨房のようなもの。
料理（SQLとデータ）だけに集中できる。
