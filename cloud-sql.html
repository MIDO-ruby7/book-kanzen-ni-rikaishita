Cloud SQLクラウドエスキューエル

ひとことでいうと

MySQL / PostgreSQL などをマネージドで使える、GCPのリレーショナルDB。

1

なぜ生まれた？

DBのバックアップやパッチを、アプリ開発の横でやり続けるのはきつい。

2

それまでどうしていた？

Compute Engine上にDBを自前構築していた。

自前DB VMCloud SQL
運用OSから自分マネージドに寄せられる
バックアップ自作機能として用意される
接続IP直IAMやコネクタ等の選択肢
対比——AWS RDSに相当
3

Cloud SQL で何ができるようになった？

定番RDBをGCP上で借りられる
運用雑務を減らせる
アプリは接続先変更で移行しやすい
ひとことメモ

Cloud SQL。SpannerやFirestoreとは役割が違う。
