gem

Rubyの宝石箱から部品を取り出す

ひとことでいうと

Rubyのパッケージ（gem）を管理する仕組み。RubyGemsと、Bundlerによるアプリ単位の固定がセットで語られる。

1

なぜ生まれた？

Rubyのライブラリ流通が増え、インストールとバージョン衝突を標準化したかった。

2

それまでどうしていた？

ライブラリを手で配置し、requireパスと格闘していた。

手動ライブラリ管理gem / Bundler
インストール配置とパス設定gem install / bundle install
アプリの固定難しいGemfile.lock で再現
公開個別配布RubyGems.org へ
衝突実行時に発覚解決をツールが支援
3

gem で何ができるようになった？

Rubyライブラリを標準手順で入れられる
Gemfileでアプリの依存を宣言できる
Railsなど生態系の前提になる
ひとことメモ

アプリ開発では Bundler 前提で考えると現場に近い。
