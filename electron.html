Electron

Webの技術だけでデスクトップアプリを作る発想

ひとことでいうと

HTML・CSS・JavaScriptで書いた画面を、そのままWindows/Mac用のデスクトップアプリとして動かす仕組み。

1

なぜ生まれた？

デスクトップアプリを作るには、OSごとに別の言語・UI部品を
覚えて実装する必要があり、コストが高かった。

2

それまでどうしていた？

それまでは、C++/C#/SwiftなどOSごとのネイティブ言語・フレームワークで別々に実装していた。

ネイティブ実装（OSごと）Electron
言語C++ / C# / SwiftなどHTML / CSS / JavaScript
対応OSOSごとに別実装が必要1つのコードで複数OSに対応
代表例—VS Code / Slack / Discordなど
3

Electron で何ができるようになった？

1つのコードで複数OSに対応
Web技術の知識をそのまま流用
ブラウザ機能ごとアプリに同梱
ひとことメモ

アプリ内にChromiumを丸ごと同梱するため、
動作は重めになりがち、というのが差分の裏側。
