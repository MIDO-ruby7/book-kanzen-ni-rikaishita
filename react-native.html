React Nativeリアクトネイティブ

ひとことでいうと

Reactのコンポーネント発想で画面を書き、実際の描画はiOS/Androidのネイティブ部品に任せるフレームワーク。

1

なぜ生まれた？

WebのReactに慣れたチームが、モバイルでも同じ思考でアプリを作りたかった。
しかも WebView ラップではなく、ちゃんとしたネイティブUIが欲しかった。

2

それまでどうしていた？

選択肢は「SwiftとKotlinで二重開発」か「ハイブリッド（WebView）」に偏りがちだった。

二重開発／WebView型React Native
言語・発想SwiftとKotlinで別々JS/TS＋Reactで共通化
UIの実体WebView or 完全別実装ネイティブ部品
ホットリロード環境次第開発中の再読み込みが速い
エコシステム各OSの流儀npmとReactの資産を活かせる
3

React Native で何ができるようになった？

React経験をモバイルに横展開できる
一本のJS/TSから両OS向けに寄せられる
ネイティブモジュールで足りない部分を足せる
ひとことメモ

「Write once, run anywhere」より「Learn once, write anywhere」と言われることが多い。
橋渡し（ブリッジ）や新規アーキテクチャの話は、深入りすると別辞典が必要。
