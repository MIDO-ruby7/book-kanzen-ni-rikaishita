ECSイーシーエス

ひとことでいうと

Dockerコンテナを、AWS上で動かし続けるためのオーケストレーションサービス。

1

なぜ生まれた？

コンテナは作れた。でも本番で何台も張り、落ちたら立て直す運用がつらい。

2

それまでどうしていた？

EC2にSSHして docker run し、プロセス監視も自前でやっていた。

EC2上の手運用ECS
配置手動タスク定義で宣言
再起動自分で対応サービスが立て直しを助ける
スケール台数を手で増減サービス単位で増やしやすい
連携自作ALBやIAMとつなぎやすい
3

ECS で何ができるようになった？

コンテナを本番運用の単位にできる
定義どおりに起動・更新しやすい
ロードバランサーと組み合わせやすい
ひとことメモ

Elastic Container Service。
Fargateと組むと「サーバーレス寄りコンテナ」、EC2起動タイプだと下地の管理が残る。
