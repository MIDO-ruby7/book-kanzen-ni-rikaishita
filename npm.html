npm

Nodeの荷物を運ぶ、公式の配達便

ひとことでいうと

Node.js付属のパッケージマネージャ。npmレジストリからパッケージを入れ、scriptsも実行する。

1

なぜ生まれた？

JSの再利用部品が増えるにつれ、ダウンロード・依存解決・公開を標準化する道具が必要になった。

2

それまでどうしていた？

スクリプトをファイルで共有するか、Gitリポジトリを직접参照する運用が多かった。

手動入手npm
インストールダウンロードして配置npm install で解決
メタデータREADME頼みpackage.json に集約
実行パスを覚えるnpm scripts で統一
公開個別配布レジストリに publish
3

npm で何ができるようになった？

JSパッケージを標準手順で入れられる
scriptsで開発コマンドを共有できる
自作パッケージを公開できる
ひとことメモ

npmはツール名でありレジストリ名でもある。
yarn/pnpmに乗り換えても、レジストリはnpmのまま、がよくある構図。
