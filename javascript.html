JavaScript

ブラウザに「動き」を与えたプログラミング言語

ひとことでいうと

Webページ内で計算や画面操作を行い、ユーザー操作に応じて動的に変化させる言語。

1

なぜ生まれた？

HTML/CSSだけでは静止した文書しか作れず、入力チェックやアニメーションなど。

2

それまでどうしていた？

それまではHTML/CSSだけの、動きのない静的なページが中心だった。

静的なHTML/CSSのみJavaScript追加後
ページの振る舞いリンクをクリックしたら別ページに遷移するだけクリックした場で表示を変えられる
入力チェックサーバーに送ってからエラー表示送信前にブラウザ内でチェックできる
更新方法ページ全体を再読み込み一部だけ書き換え可能
3

JavaScript で何ができるようになった？

クリックや入力に反応できる
ページの一部だけ書き換えられる
サーバーと通信もできる
ひとことメモ

TypeScriptはこのJavaScriptに型を足したもの。
