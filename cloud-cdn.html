Cloud CDNクラウドシーディーエヌ

ひとことでいうと

コンテンツをエッジから配り、オリジンの負荷と遅延を減らすGCPのCDN。

1

なぜ生まれた？

遠いユーザーへの配信や、オリジンへの集中アクセスがボトルネックになる。

2

それまでどうしていた？

オリジンから直接配り、遅延と負荷をそのまま受けていた。

オリジン直Cloud CDN
遅延距離依存近いキャッシュから
負荷オリジン集中キャッシュで緩和
設定自前CDNGCPのLB等と統合
対比——CloudFrontに相当
3

Cloud CDN で何ができるようになった？

配信を速くできる
オリジン負荷を減らせる
静的・動的の前段に置ける
ひとことメモ

Google Cloud CDN。負荷分散とセットで語られることが多い。
