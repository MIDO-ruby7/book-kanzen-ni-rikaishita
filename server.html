Serverサーバー

ひとことでいうと

依頼を受け取り、処理して結果を返す側のプログラムやコンピュータ。WebサーバーやAPIサーバーなどが典型。

1

なぜ生まれた？

同じ処理や同じデータを、複数の端末から共通して使いたい需要が増えた。待ち受けて応答する側が必要になった。

2

それまでどうしていた？

各端末のアプリが、それぞれ独自にデータや処理を持っていた。

端末ごとの完結Server
役割端末内で全部処理依頼を受けて処理・応答する
実体手元のアプリ常時動くプログラム／マシン
利用者自分一人向け複数クライアントから同時利用
配置端末の中データセンターやクラウド上も多い
3

Server で何ができるようになった？

リクエストを受けて処理できる
複数のクライアントに同時対応できる
共通のデータや処理を一か所に置ける
ひとことメモ

サーバーは「場所の名前」だけでなく「依頼に応える役割」も指す。同じマシンでも、動かすプログラム次第でクライアントにもサーバーにもなる。
