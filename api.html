61

API

「画面を見せずに機能だけ貸す」ための窓口

ひとことでいうと

アプリやサービス同士が、決められたルールに沿ってやり取りするための"窓口"。

1

なぜ生まれた？

外部サービスの機能やデータを自分のアプリから利用したいとき、画面をスクレイピングする以外に構造化された取得手段がなかった。

2

それまでどうしていた？

外部のサービスが持つ機能やデータを使いたいとき、以前は画面ごと取り込む（スクレイピング）しかなかった。

画面のスクレイピングAPI
取得する対象見た目込みのHTML全体必要なデータだけ
安定性デザイン変更で簡単に壊れる仕様が変わらない限り安定
やり取りの形人が読む前提のページプログラムが読む前提のデータ
3

API で何ができるようになった？

他社のサービスの機能をそのまま使える
決まったルールでデータだけをやり取り
フロントとサーバーの間の窓口にもなる
ひとことメモ

APIは「Application Programming Interface」の略。
「プログラム同士が会話するための窓口」くらいに考えるとイメージしやすい。
