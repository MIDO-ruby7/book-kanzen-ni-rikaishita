555

yarn

npmに対抗して生まれた、もう一つのクライアント

ひとことでいうと

Facebook発のJavaScriptパッケージマネージャ。高速化やロックファイル体験を武器に普及した。

1

なぜ生まれた？

npmの当時の速さ・決定性・DXに不満があり、代替クライアントが求められた。

2

それまでどうしていた？

npm install の遅さと、環境差によるずれが日常だった（当時）。

当時のnpm体験yarn
ロック弱かった時期があるyarn.lock で強く固定
速さ遅く感じることがキャッシュや並列で改善を狙う
UI素朴進捗やワークスペース体験を強化
互換——npmレジストリを利用可能
3

yarn で何ができるようになった？

JS依存を代替クライアントで管理できる
モノレポ（workspaces）運用に乗りやすい
ロックファイルで再現性を担保できる
ひとことメモ

Classic と Berry（yarn 2+）で別物感がある。
チームのREADMEに「どのYarnか」が書いてあると救われる。
