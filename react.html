React

画面を「部品」の組み合わせで作る発想を広めたライブラリ

ひとことでいうと

UIを再利用可能なコンポーネント単位で組み立てるためのJavaScriptライブラリ。

1

なぜ生まれた？

素のJS・DOM操作で画面を作ると、状態が変わるたびに
DOMを手動で書き換える処理が複雑化し、バグの温床になっていた。

2

それまでどうしていた？

それまでは jQuery などでDOMを直接操作し、画面の状態を自分で追跡・更新していた。

素のJS / jQueryReact
更新方法DOMを直接書き換え状態（State）からUIを再計算
再利用コピペで使い回しコンポーネントとして部品化
学習コスト低いJSX・Hooksなど独自の書き方あり
3

React で何ができるようになった？

画面をコンポーネント単位で管理
状態が変わると自動で再描画
Next.jsなど周辺エコシステムが豊富
ひとことメモ

差分の核は「Stateが変わったらUIも自動で追従する」という
宣言的UIの発想。それまでは全部手動だった。
