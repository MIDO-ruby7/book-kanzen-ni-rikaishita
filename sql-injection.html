SQL Injectionエスキューエルインジェクション

ひとことでいうと

入力欄にSQL文を紛れ込ませ、データベースを不正に操作する攻撃。

1

なぜ生まれた？

ユーザ入力を文字列連結でSQLにすると、入力が「データ」ではなく「命令」になる。

2

それまでどうしていた？

入力チェックを目視や部分的なエスケープに頼り、抜け道が残っていた。

文字列連結SQL対策後
入力の扱い命令になりうるパラメータとして分離
防御場当たりプレースホルダが基本
被害データ漏洩・破壊実行を防げる
検知遅いWAF等が補助になる
3

SQL Injection で何ができるようになった？

攻撃手法として名前を知れる
プレースホルダ等の防御が分かる
WAFなど多層防御の対象になる
ひとことメモ

略してSQLi。ORMを使っていても、生SQLを書く場所は要注意。
