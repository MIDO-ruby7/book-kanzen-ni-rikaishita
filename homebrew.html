Homebrewホームブリュー

ひとことでいうと

macOS（とLinux）で人気のパッケージマネージャ。brew install で開発ツールを入れられる。

1

なぜ生まれた？

MacでUNIX系ツールを入れようとすると、公式以外の手段がばらばらだった。
コミュニティ主導の統一的な入れ方が欲しかった。

2

それまでどうしていた？

ソースビルドや、サイトごとのインストーラを集めるのが日常だった。

個別インストーラHomebrew
入れ方サイトごとに違うbrew install で統一
更新個別brew upgrade でまとめて
アンインストール残骸が残りやすい手順が比較的明確
開発体験環境構築が長いオンボーディングが短い
3

Homebrew で何ができるようになった？

開発ツールをコマンド一発で入れられる
GUIアプリ（Cask）も扱える
チームのMac環境構築を揃えやすい
ひとことメモ

「まずbrew入れて」はMac開発者の儀式。
権限とパス（Apple Siliconの /opt/homebrew）は初見殺しポイント。
