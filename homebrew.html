Homebrew

ひとことでいうと

macOS（とLinux）で人気のパッケージマネージャ。brew install で開発ツールを入れられる。

1

なぜ生まれた？

MacでUNIX系ツールを入れようとすると、公式以外の手段がばらばらだった。

2

それまでどうしていた？

ソースビルドや、サイトごとのインストーラを集めるのが日常だった。

個別インストーラHomebrew
入れ方サイトごとに違うbrew install で統一
更新個別brew upgrade でまとめて
アンインストール残骸が残りやすい手順が比較的明確
開発体験環境構築が長いオンボーディングが短い
3

使用例

macOSでツールを入れる基本例。

brew install git
