Markdown

プレーンテキストのまま、見出しを付ける

ひとことでいうと

シンプルな記号で見出しやリストを表し、HTMLなどへ変換できる軽量マークアップ。

1

なぜ生まれた？

文書をリッチにしたいが、Wordや生HTMLは重すぎる／うるさすぎる。
読み書きしやすい中間が欲しかった。

2

それまでどうしていた？

プレーンテキストの無機質さか、WYSIWYGの重いファイルかの二択になりがちだった。

プレーン／Word／HTMLMarkdown
読みやすさ記号が多いか・バイナリテキストのまま構造が見える
差分つらいこともGitと相性が良い
変換——HTMLやPDFへ落とせる
方言——Flavor差には注意
3

Markdown で何ができるようになった？

READMEや仕様を軽く構造化できる
Git上でレビューしやすい文書にできる
ドキュメントサイトの入力形式になる
ひとことメモ

GitHub Flavored Markdown（GFM）を基準に覚えると実務に近い。
表やタスクリストは方言側の機能。
