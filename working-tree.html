Working Treeワーキングツリー

ひとことでいうと

今エディタで触っている、実際のファイルの状態（作業ディレクトリ）のこと。

1

なぜ生まれた？

「コミットした内容」と「今ディスク上にあるファイル」がズレると、何を保存したのか分からなくなる。

2

それまでどうしていた？

保存＝確定、の感覚だけで進めていた。

ファイル＝真実Working Tree
今の状態開いているファイル作業ツリーとして区別する
確定前上書き保存のみステージやコミットと分離
戻すバックアップ頼みcheckoutやrestoreで戻せる
差分目視working treeとHEADのdiff
3

Working Tree で何ができるようになった？

「今触っている状態」を言葉にできる
未コミット変更の居場所が分かる
作業中の変更だけ戻せる
ひとことメモ

Working Tree / Staging Area / Repository（コミット履歴）の三段が分かると、Gitが急に読みやすくなる。
