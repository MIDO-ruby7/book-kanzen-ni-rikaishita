Cloud Functionsクラウドファンクションズ

ひとことでいうと

イベントやHTTPに応じて、関数単位で動かすGCPのサーバレス実行環境。

1

なぜ生まれた？

小さな処理のために、常時インスタンスを張りたくない。

2

それまでどうしていた？

小さなWebhookもVMや常駐プロセスで受けていた。

常駐プロセスCloud Functions
単位サーバー／コンテナ関数
起動常時イベントで起動
運用OSやサーバーまでコードとトリガーが中心
課金常時稼働ぶん実行した分だけ
3

Cloud Functions で何ができるようになった？

小さい処理をサーバレスで置ける
ストレージやPub/Subとつなぎやすい
試しの自動化に向く
ひとことメモ

現在の名称はCloud Run functions。長い処理はCloud Runへ。
