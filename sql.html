SQL

ひとことでいうと

データベースに対して、検索・追加・更新・削除を指示するための言語。

1

なぜ生まれた？

データベース製品ごとに操作方法が異なると、製品を変更するたびに操作方法を一から覚え直す必要があった。

2

それまでどうしていた？

各データベース製品が、それぞれ独自の操作方法を持っていた。

製品ごとに独自SQL
学習コスト製品ごとに覚え直す一度覚えれば多くの製品で通用
書き方製品依存でバラバラになるSELECT / INSERTなど共通構文
移行製品を変えると書き直しになる基本構文はそのまま使い回せる
3

SQL で何ができるようになった？

共通の書き方でデータを操作できる
条件を指定して正確に絞り込める
多くのDB製品で同じ知識が使える
