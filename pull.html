Pull

みんなの最新を、自分の手元に引き寄せる

ひとことでいうと

リモートリポジトリの最新の変更を、自分の手元に取り込むこと。

1

なぜ生まれた？

チームメンバーが加えた変更を、自分の環境にも反映させる必要があった。

2

それまでどうしていた？

最新ファイルを送ってもらい、自分の変更と手作業で見比べながら統合していた。

手動マージPull
取得方法送ってもらう・都度依頼git pull で自動取得
統合作業目視で見比べて手作業fetch＋mergeで自動統合
最新性聞かないと分からないいつでも最新を取得できる
衝突対応気づきにくいコンフリクトとして明示される
3

Pull で何ができるようになった？

常にチームの最新に追いつける
自分の変更と自動で統合される
衝突があればその場で気づける
ひとことメモ

pull は「fetch＋merge」の合わせ技。中身を分けて考えると仕組みが理解しやすい。
