Object Storageオブジェクトストレージ

ひとことでいうと

ファイルを「オブジェクト」として大量に保存する、クラウドの保管庫。

1

なぜ生まれた？

画像や動画が増え続け、ディスクの容量管理や故障対応が重くなった。
容量を気にせず置ける保管場所として生まれた。

2

それまでどうしていた？

サーバーのディスクを増設し、容量の監視やバックアップを自分で行っていた。

ディスク運用Object Storage
容量増設が必要実質無制限
扱い方フォルダで階層管理キーとデータの組で保存
耐久性自前で冗長化複数の場所に自動複製
3

Object Storage で何ができるようになった？

大量のファイルを置く
URLで出し入れする
複製されて消えにくい
ひとことメモ

AWSではS3、Google CloudではCloud Storageが代表例。
Webサイトの画像やバックアップの置き場として、実務で最もよく使う。
