GitHubギットハブ

ひとことでいうと

Gitのリモートリポジトリを置いて、人とコードを共有・レビューできるWebサービス。

1

なぜ生まれた？

手元のGitだけでは、チームへの共有・レビュー・Issue管理がバラバラになりやすかった。

2

それまでどうしていた？

ZIPやメールでコードを送り、変更点は口頭やチャットで伝えていた。

ファイル送付GitHub
共有ZIPやメールリモートにpushして共有
レビュー画面共有や口頭Pull Requestで差分レビュー
議論の記録チャットに流れるIssueやPRに残る
公開別途用意OSS公開の定番の場になる
3

GitHub で何ができるようになった？

チームで同じ履歴を共有できる
変更を提案・レビューできる
CIやIssueと連携しやすい
ひとことメモ

Git（道具）とGitHub（置き場＋周辺機能）は別物。
「GitHubに上がってる」はリモートの話、が多い。
