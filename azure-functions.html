Azure Functionsアジュールファンクションズ

ひとことでいうと

イベントを受けて関数を動かすAzureのサーバーレス実行環境。

1

なぜ生まれた？

一日に数回しか動かない処理のためにサーバーを常時動かすのは無駄だ。
呼ばれたときだけコードを実行し、使った分だけ払う形が生まれた。

2

それまでどうしていた？

処理のたびに起動しておくサーバーを用意し、常時稼働させていた。

常時サーバーFunctions
動く条件常時起動して待機トリガーで起動
課金稼働時間ぶん実行回数と時間
スケール台数を自分で調整負荷で自動増加
3

Azure Functions で何ができるようになった？

イベントを受けて起動
関数のコードだけ用意
使った分だけ課金
ひとことメモ

Azure Functionsは、呼び鈴が鳴ったときだけ出てくる店員のようなもの。
玄関に立たせ続けなくても、客が来れば対応する。
