562

apt

ひとことでいうと

Debian/Ubuntuなどで使うパッケージ管理コマンド。OSのソフトウェアを安全に入れたり更新したりする。

1

なぜ生まれた？

Linuxにソフトを入れる方法がソースビルド中心だと、依存地獄と更新追従がつらい。

2

それまでどうしていた？

tarballを展開して ./configure && make が通過儀礼だった。

ソースからの導入apt
依存解決自分で集めるパッケージマネージャが解決
更新手作業apt upgrade で追従
削除残骸管理が難しいアンインストール手順がある
信頼ダウンロード元まちまちディストリのリポジトリ
3

使用例

Ubuntu系でパッケージ一覧更新と導入を行う例。

sudo apt update sudo apt install git
