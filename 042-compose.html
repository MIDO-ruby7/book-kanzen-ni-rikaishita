Composeコンポーズ

複数コンテナを「1 枚の設定」でまとめて動かす

インフラ
ツール
ひとことでいうと

何個ものコンテナの構成を 1 つのファイルに書いて、まとめて起動・停止できるツール。

1

なぜ生まれた？

Web・DB・キャッシュなど複数のコンテナを、
毎回手で起動するのが大変だったから。

2

それまでどうしていた？

docker run でコンテナを 1 個ずつ手動で起動していた。

docker runCompose
対象1 コンテナずつまとめて一括
設定コマンドに毎回ファイルに固定
再現性手順に依存誰でも同じ
起動何度もコマンドup 一発
3

Compose で何ができる？

構成をファイル化
up で一括起動
依存関係を自動解決
ひとことメモ

Compose は「構成の設計図」。開発環境を“ファイルごと”配れるのが強み。
