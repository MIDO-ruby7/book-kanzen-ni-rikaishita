Clone

まるごと持ち帰れる、プロジェクトのコピー機

ひとことでいうと

リモートリポジトリの中身を、変更履歴つきで手元にまるごとコピーしてくること。

1

なぜ生まれた？

他のPCやメンバーの環境に、同じプロジェクトを履歴ごと持ってくる方法が必要だった。

2

それまでどうしていた？

リポジトリの中身をZIPでダウンロードして展開していた（履歴は付いてこない）。

ZIPダウンロードClone
手に入るもの最新ファイルのみ全履歴つきのコピー
更新の追従そのつどダウンロードし直すpullで差分だけ取得
変更の反映できない・別送するしかないpush・pullで同期できる
初期セットアップ展開してまた一からやり直しgit clone のひと言で完了
3

Clone で何ができるようになった？

履歴ごと丸ごと持ってこれる
どのPCでも同じ環境を再現
続きの作業をすぐ始められる
ひとことメモ

cloneするのは最初の1回だけ。2回目以降は pull で差分だけを取ってくる。
