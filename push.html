Push

ひとことでいうと

ローカルで積み上げたコミットを、リモートリポジトリに送って反映させること。

1

なぜ生まれた？

手元で進めた作業の内容を、チームやサーバーに反映する手段が必要だった。

2

それまでどうしていた？

修正したファイルをメールやチャットで送ったり、FTPでアップロードしていた。

ファイル送付Push
共有方法メール・チャットで送付コマンド一つで送信
反映されるものファイルの最新版だけ変更履歴ごと
衝突気づかず上書きされがち衝突があれば警告される
手間そのつどファイルを探して送るgit push のひと言
3

使用例

現在のブランチのコミットをリモートへ送る例。

git push origin main
