Java

「どこでも同じように動く」を掲げ、大規模開発の標準になった言語

ひとことでいうと

JVM上で動作し、書いたコードをOSを問わず動かせることを武器に、企業システムの定番であり続ける言語。

1

なぜ生まれた？

家電向けの組み込み言語として開発が始まったが、「一度書けば、どこでも動く（Write Once, Run Anywhere）」
という思想がWeb・業務システムの世界に刺さり、企業システムの標準言語として広まった。

2

それまでどうしていた？

それまではCやC++でOSごとにコンパイルし直す必要があり、動作環境を変えるたびに移植作業が発生していた。

C / C++Java
動作環境OSごとに再コンパイルが必要JVM上でOSを問わず動く
メモリ管理手動（自分で解放）自動（ガベージコレクション）
型の厳しさ言語による静的型付けで厳格
向いている場面OS・ハードウェア寄りの処理大規模・長期運用の業務システム
3

Java で何ができるようになった？

OSを問わず動かせる
大規模開発でも破綻しにくい
企業システムの定番として実績豊富
ひとことメモ

Javaは「一度書けば、どこでも動く」を実現するためにJVMという実行環境を挟んでいる。
冗長と言われつつも、この安定感が今も選ばれ続ける理由。
