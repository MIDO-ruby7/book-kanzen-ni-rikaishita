Node.js

JavaScript を「ブラウザの外」で動かした技術

ひとことでいうと

ブラウザの中でしか実行できなかった JavaScript を、サーバーやPC上で動かせるようにするランタイム。

1

なぜ生まれた？

JavaScript はブラウザの中でしか実行できず、
サーバーサイドは別の言語で書くしかなかった。

2

それまでどうしていた？

サーバーサイドは Ruby・PHP・Java など、フロントとは別の言語で書いていた。

サーバー専用言語Node.js
言語Ruby / PHP / Java などJavaScript（フロントと共通）
実行エンジン各言語専用のランタイムChrome の V8 エンジン
得意分野汎用処理全般I/O待ちが多い並行処理
3

Node.js で何ができるようになった？

サーバーサイドをJSで書ける
フロントとバックの言語を統一
npmエコシステムを利用可能
ひとことメモ

Node.js は「JSをどこでも動かす」の元祖。
この後 Bun・Deno という2つの後継が生まれることになる。
