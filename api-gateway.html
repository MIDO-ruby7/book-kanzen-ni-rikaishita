API Gatewayエーピーアイゲートウェイ

ひとことでいうと

HTTP APIの入口を作り、認証やルーティングを前段で引き受けるサービス。

1

なぜ生まれた？

Lambdaや微服务に、そのままインターネットを晒すのは怖いし面倒。

2

それまでどうしていた？

アプリサーバーに直接APIを生やし、認証もCORSも全部アプリでやっていた。

アプリ直公開API Gateway
入口各サービスごとゲートウェイに集約
認証自前実装仕組みを載せやすい
スロットルアプリ任せ前段で制限できる
接続先固定サーバーLambda等へつなげる
3

API Gateway で何ができるようになった？

APIの正面玄関を作れる
認証や制限を前段に寄せられる
サーバレス構成の入口になる
ひとことメモ

REST API / HTTP API など種類がある。
「API」そのものではなく、入口の装置。
